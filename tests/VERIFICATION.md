# 第一版验证记录

2026-10-23，在本机 Node.js 24 和 Codex 内置浏览器中验证。

## 自动检查

- `npm run check`：三个 JavaScript 模块语法检查通过。
- `npm test`：7 项测试通过，覆盖备份往返、导入边界校验、鼠标缩放坐标、分组成员识别、撤销重做和连线几何计算。

## 浏览器实际操作

- 双击原有便签打开其编辑表单。
- 新建便签并填写多行文本，勾选待办，刷新后内容和完成状态仍在。
- 搜索文字，侧栏结果与卡片强调状态更新。
- 选择连接工具，点击两张卡片，填写连线说明；撤销说明、撤销连接成功。
- 拖动分组标题，验证分组与内部卡片具有相同位移。
- 上传 PNG 图片，验证转换后的内嵌图片正常加载。
- 导出 JSON 并从下载文件重新导入，验证 7 个测试内容项、3 条连线和两张图片（其中一张内嵌）完整恢复。
- 恢复随项目提供的五张示例卡片，刷新清除验收操作历史。
- 在 1440 × 900 桌面视口检查布局，示例便签无内容溢出。
- 恢复浏览器原有 470px 窄屏尺寸，检查侧栏折叠、工具栏可见、首张卡片可读且页面没有横向滚动。
- 浏览器检查过程中未记录到 JavaScript 错误。

桌面预览保存在 `test-results/思想画布-桌面预览.png`，测试过程文件位于被 Git 忽略的 `test-results/`。
