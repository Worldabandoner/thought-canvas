# 思想画布

让脑中的画面、位置和逻辑，在一张自由画布上显现。第一版使用原生 HTML / CSS / JavaScript，没有外部字体、CDN、框架依赖或构建步骤。

## 本地启动

安装 Node.js 20 或更高版本，在本目录打开终端：

```powershell
npm start
```

打开 **http://127.0.0.1:5173**。也可以双击 `启动思想画布.cmd`。无需执行 `npm install`。

指定端口或允许局域网访问：

```powershell
$env:PORT = '8080'
$env:HOST = '0.0.0.0'
npm start
```

不要通过双击 `index.html` 的 `file://` 方式使用，请通过 HTTP 服务打开。

## 当前功能（V1.3）

V1.1 将品牌、导出、导入及本地保存状态整合到左侧栏，移除了独立顶部栏。画布占满页面高度，左侧栏可随时收起；窄屏默认收起，点击画布左上角的侧栏按钮展开。导入备份入口位于左侧栏底部的「更多选项」。

V1.2 新增时间卡片、精确截止时间、完成数量进度和左侧「即将到期」列表。

V1.3 新增「我的画布」管理页：像选择不同项目一样打开独立画布，支持缩略图、新建、搜索、重命名、复制及回收站。侧栏顶部可快速切换画布，进入后仍保留完整的画布工作区。

- 无限画布：平移、围绕鼠标缩放、回到全部内容。
- 文字便签：标题、正文、六种柔和颜色。
- 待办卡片：多个子任务、完成进度、精确到分钟的可选截止时间，以及可选的开始时间。
- 时间卡片：支持重要事件倒计时；可填写已完成数量、目标数量和单位，通过卡片上的加减按钮更新进度。
- 图片：选择文件、拖入或粘贴，支持 PNG / JPG / WebP / GIF；存储时缩放到最长边 1800px，转为 WebP，GIF 使用首帧。
- 分组区域：拖动标题、框内空白或普通边框，会携带完全包含在区域内的卡片；右下角调整范围。按住空格或使用漫游工具仍可拖动画布。
- 复制分组：同时复制框内卡片与内部连线，保留文字、图片、待办状态及相对位置；副本放到现有内容右侧并自动定位，避免与原件重叠。删除分组仍只移除框。
- 关系连线：依次点击两张卡片，设置说明和方向箭头。端点跟随卡片移动。
- 卡片和分组尺寸调整、复制、删除，最多 40 步撤销 / 重做。
- 左侧内容搜索、待办索引，点击索引定位。
- 浏览器 IndexedDB 自动保存，JSON 完整备份与恢复（含上传图片）。

工具栏选择便签 / 待办 / 分组后，点击画布放置，再填写内容。双击卡片或点击其右上角菜单可编辑，拖动右下角改变大小。

## 数据保存与迁移

### 多画布的使用

默认启动进入「我的画布」。点击缩略图或「打开」进入画布；侧栏顶部可切换到最近打开的画布，点击「我的画布 / 新建」返回管理页。「启动时自动打开上次画布」可改变启动方式。

每张画布分别保存内容、连线、分组、时间进度和视角。切换前会等待当前内容保存成功；保存失败则保留当前工作区并提示导出备份。撤销 / 重做只作用于当前画布，切换后重新开始记录，不会撤销其他画布的内容。

复制画布会保留全部内容与视角，生成独立的副本。移入回收站后可恢复，回收站不参与提醒；永久删除需要再次确认。回收站不会自动清空，也占用浏览器空间。

升级时自动将旧版的当前画布迁移为第一张画布，旧记录保留不删除。请关闭其他旧版本窗口，再刷新使用新版；同一个画布库被多个新版窗口修改时，后保存的窗口会阻止覆盖并提示先备份、再刷新。系统没有实时多人协作功能。

### 时间提醒的使用

点击底部「时间」工具或按 `C`，在画布上选一个位置，填写标题和目标时间。开始时间用于计算「时间已过」进度；目标数量大于 0 时显示独立的「完成进度」，目标数量为 0 时只展示倒计时。进度达到目标或手动标记完成后，会从待提醒列表移除；减少完成数量后可继续提醒。

已有待办可双击编辑截止时间。剩余超过 24 小时以柔和色展示，24 小时内变为橙色，2 小时内及逾期变为红色。长期事件显示剩余天数和小时，短期事项显示小时、分钟；到期不等于任务完成。

左侧「即将到期」默认跨所有画布，按截止时间列出未完成的定时事项（包括长期事件），逾期事项排在前面。每项标注所属画布，点击会打开对应画布并定位卡片。可以改为只查看当前画布；回收站内的画布不参与提醒。系统不会重新摆放卡片。

倒计时在网页可见时约每 15 秒刷新，重新打开或切回网页时立即按当前时间计算。没有网页外通知。日期按设置时的设备本地时区输入，保存为带 UTC 时区的时间点；换设备后按新设备的本地时区显示。

项目另附 `时间提醒示例.json`，包含短期网课、长期事件及逾期待办演示。考试日期仅为演示，请自行填写实际安排。导入示例会新增一张画布；重复导入会再次新增，保留原画布。

### 兼容性

V1.2 使用数据格式 v2，并支持自动读取旧版 v1 画布。旧版仅日期的截止时间按该设备当天 23:59:59.999 转换。新导出的 v2 备份应使用 V1.2 或后续版本恢复。

V1.3 单张画布继续使用 v2 格式；整库备份使用独立的 `thought-canvas-library` v1 格式，包含所有画布、回收站和启动偏好，需要 V1.3 或后续版本读取。导入整库备份时以新 ID 添加画布，并保留备份中的回收站状态；当前库的启动偏好保持不变。

**本版本没有服务端数据库、账号或多端同步。** 数据保存在当前网址对应的浏览器 IndexedDB 中。服务器仅提供静态文件，不会收到画布内容。不同域名、端口、浏览器之间不会共享数据；清除站点数据会删除画布。

迁移到服务器前，在管理页点击「导出整个画布库」，包含回收站和内嵌图片；仅需一张画布时使用侧栏底部「导出画布」。在服务器网址打开后，从管理页「导入备份」或侧栏「更多选项 → 导入为新画布」恢复。建议定期导出，尤其在清理浏览器数据前。导入始终新增画布，不会覆盖原有内容。

项目附有 `示例画布.json`，需要重新体验初始示例时，可以通过相同的导入入口恢复。

`画布库示例.json` 包含「灵感角落」「学习计划」「工作空间」三张独立画布，可用来体验多画布管理；学习计划中的日期仅用于演示。

画布库支持最多 100 张画布（含回收站），每张支持 1000 个内容项、3000 条连线；单次最多上传 12 张图片，单张原图不超过 25 MB，导入备份不超过 120 MB。实际容量受浏览器存储空间限制，保存失败时会提示导出备份。适合个人桌面使用，小屏幕提供折叠侧栏与触屏拖动；暂未实现双指捏合缩放与多人协作。

## 部署到自己的服务器

只需部署以下文件，**保留其相对目录结构**：

```text
index.html
styles.css
app.js
model.js
assets/
  favicon.svg
  landscape.svg
```

直接将它们放入 Nginx / Apache 的静态站点目录即可，既支持根路径，也支持 `/canvas/` 等子路径。无需 Node.js 运行时，也无需构建。示例 `nginx.conf.example` 假定站点目录为 `/var/www/thought-canvas`，域名需要自行替换。推荐使用 HTTPS。

也可通过内置 Node.js 服务运行，服务器上设置 `HOST=0.0.0.0`，再由反向代理转发至指定端口。该服务仅允许访问应用静态文件，不暴露本目录里的其他文件。

## 检查


`model.js` 包含数据结构、导入校验、坐标换算和撤销历史；`app.js` 包含交互与 IndexedDB 保存逻辑。

## Git 版本管理

项目已建立 Git 仓库，默认分支为 `main`。初版保留为 `v1.0.0`，左侧栏整合为 `v1.1.0`，分组修复为 `v1.1.1`，时间提醒为 `v1.2.0`，多画布管理为 `v1.3.0`。通过 `git log --oneline` 查看修改记录，`git diff v1.2.0 v1.3.0` 比较本次功能更新。

Git 跟踪项目源码、示例画布和文档；生成的部署 ZIP、测试截图和运行日志已忽略。个人画布数据位于浏览器中，需要另外导出 JSON 备份。远程仓库为 `https://github.com/Worldabandoner/thought-canvas`；同步源码不会同步浏览器中的个人画布。
