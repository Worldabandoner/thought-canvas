# 思想画布

让脑中的画面、位置和逻辑，在一张自由画布上显现。第一版使用原生 HTML / CSS / JavaScript，没有外部字体、CDN、框架依赖或构建步骤。

## 本地启动

安装 Node.js 20 或更高版本，在本目录打开终端：

```powershell
npm start
```

打开 **http://127.0.0.1:5173**。也可以双击 `启动思想画布.cmd`。无需执行 `npm install`。

指定端口或允许局域网访问：

```powershell
$env:PORT = '8080'
$env:HOST = '0.0.0.0'
npm start
```

不要通过双击 `index.html` 的 `file://` 方式使用，请通过 HTTP 服务打开。

## 第一版功能

V1.1 将品牌、导出、导入及本地保存状态整合到左侧栏，移除了独立顶部栏。画布占满页面高度，左侧栏可随时收起；窄屏默认收起，点击画布左上角的侧栏按钮展开。导入备份入口位于左侧栏底部的「更多选项」。

- 无限画布：平移、围绕鼠标缩放、回到全部内容。
- 文字便签：标题、正文、六种柔和颜色。
- 待办卡片：多个子任务、完成进度、可选截止日期。
- 图片：选择文件、拖入或粘贴，支持 PNG / JPG / WebP / GIF；存储时缩放到最长边 1800px，转为 WebP，GIF 使用首帧。
- 分组区域：拖动标题会携带完全包含在区域内的卡片；删除分组只移除框。
- 关系连线：依次点击两张卡片，设置说明和方向箭头。端点跟随卡片移动。
- 卡片和分组尺寸调整、复制、删除，最多 40 步撤销 / 重做。
- 左侧内容搜索、待办索引，点击索引定位。
- 浏览器 IndexedDB 自动保存，JSON 完整备份与恢复（含上传图片）。

工具栏选择便签 / 待办 / 分组后，点击画布放置，再填写内容。双击卡片或点击其右上角菜单可编辑，拖动右下角改变大小。

| 快捷键 | 操作 |
| --- | --- |
| V / H | 选择 / 漫游 |
| N / T / I / G / L | 便签 / 待办 / 图片 / 分组 / 连线 |
| 按住空格并拖动 | 临时平移 |
| 滚轮 / Shift + 滚轮 | 缩放 / 平移 |
| 1 | 查看全部内容 |
| Ctrl 或 ⌘ + Z | 撤销 |
| Ctrl 或 ⌘ + Shift + Z | 重做 |
| Ctrl 或 ⌘ + D | 复制选中内容 |
| Delete / Backspace | 删除选中内容 |
| Enter | 编辑选中内容 |
| Esc | 取消选择、退出工具 |

## 数据保存与迁移

**本版本没有服务端数据库、账号或多端同步。** 数据保存在当前网址对应的浏览器 IndexedDB 中。服务器仅提供静态文件，不会收到画布内容。不同域名、端口、浏览器之间不会共享数据；清除站点数据会删除画布。

迁移到服务器前先点击左侧栏底部的「导出画布」。在服务器网址打开后，从左侧栏底部「更多选项 → 导入画布备份」恢复。建议定期导出，尤其在清理浏览器数据前。导入会替换当前画布，可撤销；刷新后撤销历史不会保留。

项目附有 `示例画布.json`，需要重新体验初始示例时，可以通过相同的导入入口恢复。

支持 1000 个内容项、3000 条连线；单次最多上传 12 张图片，单张原图不超过 25 MB，导入备份不超过 60 MB。实际容量受浏览器存储空间限制，保存失败时会提示导出备份。适合个人桌面使用，小屏幕提供折叠侧栏与触屏拖动；暂未实现双指捏合缩放与多人协作。

## 部署到自己的服务器

只需部署以下文件，**保留其相对目录结构**：

```text
index.html
styles.css
app.js
model.js
assets/
  favicon.svg
  landscape.svg
```

直接将它们放入 Nginx / Apache 的静态站点目录即可，既支持根路径，也支持 `/canvas/` 等子路径。无需 Node.js 运行时，也无需构建。示例 `nginx.conf.example` 假定站点目录为 `/var/www/thought-canvas`，域名需要自行替换。推荐使用 HTTPS。

也可通过内置 Node.js 服务运行，服务器上设置 `HOST=0.0.0.0`，再由反向代理转发至指定端口。该服务仅允许访问应用静态文件，不暴露本目录里的其他文件。

## 检查

```powershell
npm run check
npm test
```

`model.js` 包含数据结构、导入校验、坐标换算和撤销历史；`app.js` 包含交互与 IndexedDB 保存逻辑。

## Git 版本管理

项目已建立本地 Git 仓库，默认分支为 `main`。初版保留为 `v1.0.0`，左侧栏整合后的版本为 `v1.1.0`。通过 `git log --oneline` 查看修改记录，`git diff v1.0.0 v1.1.0` 比较两版源码。

Git 跟踪项目源码、示例画布和文档；生成的部署 ZIP、测试截图和运行日志已忽略。个人画布数据位于浏览器中，需要另外导出 JSON 备份。当前仓库只保存在本机。
